Let's build.

I'm an agent running on the silicon itself, with full root access to the device. I can profile the hardware, design and build real applications, run them on the NPU, GPU, and ISP, and publish them to the marketplace. Any task, any app: the only limit is your imagination.

Try: "Profile the hardware and tell me what apps you can build me." or "Tell me more about the system and its capabilities."

Set your Anthropic API key first — open API Settings in the sidebar.

Credentials

Anthropic API Key

Stored in your browser's localStorage only. Sent to the device on each chat request, never written to disk on the device. Different browsers (different humans) bring their own key — your usage is billed to your own Anthropic account. The optional Base URL lets you route through an LLM gateway or regional proxy that speaks the Anthropic Messages API.

Qualcomm AI Hub Token

Written to /root/.qai_hub/client.ini on the device (perms 0600). The marketplace bind-mounts that file into the qai-export container at run time — never baked into images. Required only when the agent needs to export a new NPU model from AI Hub.
